# WooCommerce Advanced Tools

WooCommerce administration utilities, developed **Premium-first** by YoOhw.

This repository is in its initial workflow bootstrap stage; no installable plugin or public release exists yet. Its current public visibility does not authorize publishing proprietary code, customer data, credentials or distribution artifacts.

Development governance is proposed in [AT-1](https://github.com/yoohwz/wc-advanced-tools/issues/1). All changes after this one-time empty-repository initialization are to be proposed through an Issue/branch/PR and merged only on explicit Human authorization.

Product focus: safe import/export, bulk operations and data-health tools. A future Free/Freemium split is intentionally outside the initial Premium scope.
